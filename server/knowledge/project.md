# Portfolio Projects

## eCommerce Marketplace

A full-stack marketplace built with React, Redux, and Express. Features include MongoDB, Redis, JWT authentication, Stripe payments, Cloudinary uploads, Socket.IO, Swagger documentation, validation, rate limiting, and security middleware.

Repository: https://github.com/SadeepaAmaranayake/eCommerce-marketplace

## IC Marketplace

A TALL-stack marketplace for searching, comparing, and sourcing integrated circuits. It includes component specifications, availability, pricing, sourcing requests, and AI-assisted compatibility suggestions.

Technologies: Laravel, Livewire, PHP, Tailwind CSS.

Repository: https://github.com/SadeepaAmaranayake/IC-Marketplace

## Real-Time Chat

A full-stack chat application with authenticated sessions and real-time WebSocket messaging.

Technologies: React, Vite, Zustand, Express, Socket.IO, and JWT.

Repository: https://github.com/SadeepaAmaranayake/chat-application

## Smart Study Buddy

A React and TypeScript study companion using Supabase, TanStack Query, React Hook Form, Zod, Tailwind CSS, Radix UI, charts, and Vitest.

Repository: https://github.com/SadeepaAmaranayake/smart-study-buddy

## Habit Tracker

A PHP and MySQL application with registration, login, progress tracking, statistics, and study, reading, and music workflows.

Repository: https://github.com/SadeepaAmaranayake/habit_tracker

## Cashflow

A React Native and Expo personal-finance application for tracking income, expenses, balances, transactions, monthly reports, and spending charts. Its backend uses Express and MongoDB.

Repository: https://github.com/SadeepaAmaranayake/cashflow
